# car-rental-system

CLI-based car rental management application built with Python and SQLite.

## Requirements

- Python 3.8+
- No external dependencies

## Setup
- python3 -m venv venv
- source venv/bin/activate    # macOS/Linux
- venv\Scripts\activate       # Windows

## Run
- python main.py

DB auto creates on initial run

## Default Admin Login

- Username: `admin`
- Password: `admin123`

## Features

- Customer, Admin, and Guest user roles
- Browse and book cars
- Smart Pricing Engine (duration, loyalty, season, lead time)
- View, cancel, and modify bookings
- Admin car management and booking override
